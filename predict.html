外部可调用 API 接口（CORS 开放 · GitHub Pages + GitHub Actions）
GEThttps://renju4433.github.io/api/index.json

查询全部已收录赛事列表、各轮状态与接口路径。

GEThttps://renju4433.github.io/api/{slug}/r{round}.json

查询指定赛事第 N 轮对阵表、双方 Glicko 等级分、预测胜率与实际赛果（如 shanhai/r9.json）。

GEThttps://renju4433.github.io/api/{slug}/standings/r{round}.json

查询第 N 轮名次表、小分、夺冠/前三/前八概率、期望名次与完整名次分布二维数据。

GEThttps://renju4433.github.io/api/{slug}/metrics.json

查询模型实战评估指标（命中率、Log-Loss、Brier 分数、分轮明细）。

GEThttps://renju4433.github.io/api/players.json

查询全库棋手最新 Glicko-1 等级分（r）与波动度（rd）。

POSThttps://api.github.com/repos/renju4433/renju4433.github.io/dispatches

通过 GitHub Action 远程触发批量对局预测（结果写入 https://renju4433.github.io/api/predict.json）或录入赛果（event_type: "apply"）：

curl -X POST https://api.github.com/repos/renju4433/renju4433.github.io/dispatches \
  -H "Authorization: Bearer <GITHUB_TOKEN>" \
  -H "Accept: application/vnd.github+json" \
  -d '{"event_type":"predict","client_payload":{"rule":"塔拉山口-10","base_time":3600,"increment":30,"games":[{"black":"赵云","white":"万俊宏"}]}}'
